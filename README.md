# Electronic Attendance Register and Classroom Monitoring System

This project is an ESP32-based electronic attendance and classroom monitoring system designed for lecture environments. It uses fingerprint biometric authentication for attendance registration and monitors classroom temperature in real time, with automatic fan control when the room becomes hot.

## Key Features

* Fingerprint-based student attendance
* ESP32-WROOM-32 microcontroller
* R307 fingerprint sensor
* DHT22 temperature and humidity monitoring
* DS3231 real-time clock module
* OLED display for system feedback
* Automatic fan control
* Web dashboard integration
* Offline data backup support

## Hardware Components

* ESP32-WROOM-32
* R307 Fingerprint Sensor
* DHT22 Temperature and Humidity Sensor
* DS3231 RTC Module
* 0.96-inch I2C OLED Display
* L298N Motor Driver
* 12V DC Cooling Fan
* Active Buzzer
